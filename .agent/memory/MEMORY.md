# MEMORY

## プロジェクト概要
- AI業務自動化支援ビジネスの起業準備。会社員のまま副業でスタート(2026年7月開始)、最終目標はストック収益化(ほぼ不労)
- 戦略の骨子：入口=行政書士(知人にいる、月3万パイロット+月2〜3万保守+紹介パートナー) → 本命=顧問先中小企業への月8〜15万リテイナー → 出口=業種特化プロダクト(月1〜3万×N)
- 全体計画は `.output/roadmap.html`(Artifact: https://claude.ai/code/artifact/a8a1a8f3-eae4-44cf-9f0b-4f345e7c4a8f)
- 調査データ・決定事項の詳細は `.spec/KNOWLEDGE.md` を参照(重複させない)

## 学習した知識・教訓
- **計画は裏取りしてから確定する**(2026-07-03)：初版ロードマップを監査した結果、4つの重大な修正が必要だった——①行政書士の76%は年商500万未満で本人に月10万リテイナーは売れない ②知人1人依存(N=1)は計画停止リスク、見込みは3〜5件並行 ③収益グラフが楽観単線だった→悲観/中央値/楽観の3シナリオ化 ④個人事業主は単独でIT導入支援事業者になれない(補助金の安請け合い禁止)
- ニッチ選定は市場データより「今週アクセスできる顧客がいるか」を優先して決めた
- 顧客の選別基準：「仕事を断ることはありますか?」がYesの忙しい相手だけ。暇な事務所は時間が浮いても売上にならず解約する
- 収益計画は中央値シナリオ(24ヶ月で月30万・うち仕組み収入8万)で立て、楽観(月55万)は達成条件つき上振れとして扱う
- 効果測定はBeforeを開発前に測る。無料案件はやらない(最低月3万)
- 到達確率の見立て：90日で初売上60〜70% / 12ヶ月で月15〜30万は40〜50% / 楽観シナリオは10〜20%。最大の脱落要因は「週10時間×18ヶ月の継続」
