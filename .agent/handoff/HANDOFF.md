## 注意点・ブロッカー

- **【新】⚠️Codexの利用枠が8/2 15:10まで無い**。画像生成を伴う作業は計画から外すか、時期をずらす
- **【新】Codexは「起動時のcwd配下」にしか書けない**。プロジェクト内に保存させたいなら**必ずプロジェクトディレクトリをcwdにして起動する**。scratchpadでプロンプトを組み立てた流れでそこをcwdにすると、絶対パス指定でも書けずに黙って作業領域へ落ちて exit 0 で返る（`./` と `./output/` を探せば回収できる）
- **【新】Codexは exit 1 でも成果物があることがある**。exit codeを信じず `ls` で判定する
- **【新】note入稿の画像枚数検証は `figure` ではなく `img` の数で数える**。noteは引用ブロックを `<figure><blockquote>…</blockquote><figcaption></figcaption></figure>` で保存するため、「今日の1個」の引用がfigureとして1件混じる（`note-draft-post/SKILL.md`に追記済み）
- **【新】スキは公開当日で止まらない**。実績を比較するときは経過日数を添える。公開直後の数字だけで記事の良し悪しを判定しない
- **原稿を書く前に、ハルト本人の実態をヒアリングする**（3本連続で記事の型が変わっている）。「その習慣が実際にあるか」「実際にやったことがあるか」を聞かずに書くと指南型になって書き手と主張がズレる
- **執筆後に見出しを声に出して読む**。体言止めの見出しは自分でも普通に書いてしまう（vol.17で2件・vol.18で2件）
- **新しいネタを仕込むときは、過去記事の該当節を実際に読んで食い合いを潰す**（vol.18とvol.15で実施）
- **OpenAI公式サイトは403で読めない**。仕様の裏取りはヘルプセンターの引用が載った検索結果＋公的機関のガイドで固める。Anthropicは `privacy.claude.com` が読める
- **`javascript_tool` の戻り値も `[BLOCKED: Cookie/query string data]` になる**。img.srcの配列をそのまま返すと署名付きクエリが原因で戻り値まるごとブロックされる→`.includes('assets.st-note.com')` の真偽値や件数に変換して返す
- **保存済みでも「Leave site?」が毎回出る**。✓とトーストを両方確認していれば警告は無視してよい。**ただし✓とトーストの確認を省いてforceするのは厳禁**
- **noteのAI自動翻訳はオンのまま維持で確定**。毎回確認しない。**有料記事を出すときだけ、翻訳版での有料部分の扱いを事前確認する**
- **公開済み記事を「更新する」とXへ自動共有が再発火する**。現在はユーザーが**note設定のX連携を手動解除済み**なので飛ばない。**連携を戻すときは、既存記事の更新をしない前提で戻すこと**
