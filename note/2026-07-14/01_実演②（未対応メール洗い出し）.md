# 「あのメール、返したっけ？」AIが返信し忘れを見つけて、Gmailに返信の下書きまで作ってくれた

前回は、メール・書類・予定をAIが横断して「次にやること」をまとめてくれる実演をお見せしました。
今日は第2弾。**「未対応メールの洗い出し」から始めて、返信の下書きまでAIにやってもらいます。**
しかも今回、AIは回答欄に文面を書くんじゃなくて——**Gmailの下書きフォルダに、そのまま送れる状態で下書きを作ってくれました**。

## 今日のあるある：「あのメール、返したっけ？」問題

受信箱って、こうなってませんか？

- 「開封しただけで返信してない」メールが混ざってる
- 急ぎじゃないから後で……と思ったまま3日経ってる
- 夜ふとんの中で「あれ返したっけ…」と急に不安になる

今回のダミー受信箱がまさにこの状態です。5通のうち、返信済みは田中建設さんの2通だけ。あとの3通は開いたまま放置——という設定にしてあります。

〔画像2：`demo02_1_受信箱.png`（Before：ダミーの受信箱。返信済み・未返信が混ざった5通）〕

一覧をパッと見ても、どれに返したかは分かりませんよね。
本当に知りたいのは「読んだか」じゃなくて **「返したか」** なんです。

## ステップ1：まず、返信し忘れを洗い出す

AIにこう打ちました。

> 受信箱を見て、まだ返信していないメールを一覧にして。急ぎのものから並べて

特別な設定も、難しい書き方も何もなし。
返ってきたのがこちらです（※中身は全部ダミーです）。

```
受信箱の未読メールは3件あります。急ぎ度順に並べました。

1. 佐藤設計事務所 佐藤美咲様（件名：新規案件のご相談（打ち合わせのお願い））
店舗リノベーションの新規案件について、来週中の打ち合わせを希望されています。
日程候補の返信が必要で、時間的制約があるため最優先です。

2. 鈴木商店 鈴木健太様（件名：請求書の送付先変更のご連絡）
来月分から請求書の送付先が変更になるとの連絡。受領確認の返信をしておくのが
望ましいです。

3. 山本工務店 山本様（件名：先日はありがとうございました）
先日の現場対応へのお礼メール。緊急性は低いですが、簡単な返信で良い印象を
保てます。

なお、これは「未読」メールに基づくリストです。既読だけどまだ返信していない
メールがあれば教えてください、それも探します。
```

〔画像3：`demo02_2_洗い出し結果.png`（指示の1行と洗い出し結果）〕

返信済みの2通はちゃんと除外して、残り3通を**急ぎの理由つき**で並べてくれました。
うまいなと思ったのは3番の扱いです。お礼メールに「緊急性は低いですが、簡単な返信で良い印象を保てます」って、優先度だけじゃなく**付き合い方まで**添えてくる。

ひとつ正直に書いておくと、最後の一文にある通り、今回のリストは「未読」を手がかりにしたものです。AI自身が「既読で未返信のものも探せます」と申し出てくれているので、開封済みの放置メールが多い人は「既読も含めて、返信していないものを探して」と頼めばOKです。

## ステップ2：カレンダーの空きを見て、返信を下書きしてもらう

ここからが今日の本番です。
最優先だった佐藤さんのメールは「来週中に打ち合わせしたい。都合のいい日時をいくつかほしい」という内容でした。

日程調整の返信って、地味に面倒じゃないですか？
カレンダーを開いて、空いてる日を探して、メールに戻って、候補を書いて……と**画面を行ったり来たり**するやつです。

そこで、続けてこう打ちました。

> 佐藤さんのメールに返信の下書きを作って。来週のカレンダーの空きを確認して、打ち合わせの候補日時を3つ入れて

すると、AIはまず**自分でカレンダーを見にいきます**。そのあと、ちょっと驚くことが起きました。
「**あなたのGmailに下書きを作成していいですか？**」と、許可を求めてきたんです。

〔画像4：`demo02_3_下書き許可.png`（AIがカレンダーを確認し、Gmailへの下書き作成の許可を求めてくる画面）〕

許可すると、最終的な報告がこちら。

```
来週の空き状況を確認し、返信の下書きを作成しました。

来週の予定（7/20〜7/24）
・7/20(月) 14:00-16:00 現場調査（西口ビル）
・7/21(火) 10:00-11:00 田中建設 打ち合わせ
・7/23(木) 13:00-14:00 オンライン定例

下書きに入れた候補日時
・7/21(火) 14:00〜15:00
・7/22(水) 10:00〜11:00
・7/24(金) 14:00〜15:00

いずれも既存の予定とかぶらない時間帯です。下書きはGmailの下書きフォルダに
保存済みなので、内容を確認して送信してください。
```

〔画像5：`demo02_4_候補と完了報告.png`（候補日時と完了報告の全体）〕

候補の3つは、どれも既存の予定を避けた時間帯。7/21(火)は午前に田中建設さんとの打ち合わせが入っている日ですが、ちゃんと午後を提案してきています。

そして実際にGmailの下書きフォルダを開くと——返信がもう、できあがっていました。

〔画像6：`demo02_5_Gmail下書き.png`（Gmailの下書きフォルダに作られた返信の実物）〕

```
佐藤設計事務所
佐藤美咲様

いつもお世話になっております。

このたびは店舗リノベーションの件でご相談いただき、誠にありがとうございます。
ぜひ一度お打ち合わせのお時間をいただければと存じます。

つきましては、来週の候補日時を以下の通りご案内いたします。
オンライン・対面どちらでも対応可能です。

・7月21日（火）14:00〜15:00
・7月22日（水）10:00〜11:00
・7月24日（金）14:00〜15:00

ご都合の良い日時がございましたら、対面/オンラインのご希望とあわせてお知らせください。
上記でご都合が合わない場合は、他の日程も調整いたしますのでお気軽にお申し付けください。

どうぞよろしくお願いいたします。
```

細かいところですが、佐藤さんのメールにあった「オンラインでも対面でも大丈夫」という一文を拾って、**「対面/オンラインのご希望とあわせてお知らせください」** と返しているんですよね。元のメールをちゃんと読んで書いている証拠です。

回答欄の文章をコピペする必要すらなくて、**あとは下書きを開いて、確認して、送信ボタンを押すだけ**。
最後の報告の締めが「内容を確認して送信してください」なのも、いいなと思いました。送るかどうかの判断は、ちゃんと人間に残してくれています。

使う側がやったのは、今日も指示2回だけ。
返信漏れ1つが信用に直結する一人事業だからこそ、毎日効くレシピだと思ってます。

## 使うときの注意（大事なので毎回書きます）

- この実演も**全部ダミーデータ**です。個人情報は入れずに試すのが鉄則
- AIがやるのは「まとめ」と「下書き」まで。**送る・確定するのは必ず人間**
- 「AIで全部自動！」ではなく、**「判断は人のまま、下ごしらえだけAIに」** が現実的で安全です
