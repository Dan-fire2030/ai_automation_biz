### 失敗したアプローチ・つまずき

- **⛔丸ゴシックで疑似ボールドをかけたら漢字が潰れた。** ヒラギノ丸ゴは **W4の1ウェイトしかない**ので、太字を `stroke_width` で作らせたところ「読」「長」「混」の内側が埋まって黒い塊になった
  - → 切り分けた結果：**ttcのindex（Pro/ProN）は無関係。`stroke_width=0` なら両方正常。38pxで2は確実に潰れ、1でも言偏が埋まりかける。23pxではさらに酷い**
  - → **対処＝疑似ボールドを全廃し、サイズで補う**（タイトル38→44px、サブタイトル23→24px）。丸ゴを使うときは今後もこの方針
- **⛔`codex:codex-rescue` への継続依頼が「前のタスクがまだ実行中」で弾かれた**（Exit code 1）。修正依頼が届いておらず、ファイル監視が空振りしかけた
  - → **対処＝`/codex:status` で前タスクの完了を確認してから実行するよう指示して再送**。継続依頼が通らないことがある前提で、**送った後は必ずファイルのmtime変化で着弾を確認する**
- **⛔Codexが、こちらでリネーム済みのファイルの複製を勝手に復活させた。** 丸ゴ版を `memo_0_ヘッダー.png` にリネームした後、Codexが `memo_0_ヘッダー_丸ゴ案.png` を同一内容・同一mtimeで戻していた → ハッシュ一致（SHA-256）を確認して削除。**委譲後はフォルダの中身そのものを `ls` で見ること**（依頼した1枚だけ見ても気づけない）
