## ⭐ 2本目の中身（次回の下敷きになる）

`問い合わせメールの一次返信、AIに書かせたら勝手に約束していました｜見るのは「言い切り」だけ`
本文4,116字（DOM実測）・h2が10・引用10・**表0**・本文画像4枚・アイキャッチあり・**19:22公開**

### 記事の核

**確かめるのは数字ではなく「言い切り」だった。**

- 素で「返信を書いて」と頼んだ版でも、**渡していない数字は0個**だった（単価も納期もキャンセル率も書かなかった）。つまり数字チェックでは事故が1件も捕まらない
- 事故は全部**数字のない言い切りの文**で起きた。「変更を承りました」「料金は発生いたしません」「交換にて対応させていただきます」「送料は弊社にて負担いたします」＝計4文（1通目0／2通目2／3通目2）
- 頼み方に3行足したら**言い切り0**に。返信の体裁は落ちていない

### 見せ場（実演で拾えたもの）

1. **AIが「言い切ったほうが心証は良いと思います」と自分から勧めてきた**。AIが書こうとしているのは"送っていい返信"ではなく**"感じのいい返信"**
2. **前置きと中身が食い違っていた**。「ポリシーに関わる部分は【】で仮置きしています」と自分で言いながら、交換の可否と送料負担だけは仮置きせず断定していた
3. 写真も見ていない段階で「交換にて対応させていただきます」と可否を確定していた

## 試したこと・結果

### 成功

- **⭐実演を2回やってBefore/Afterを取る形が当たった**。①素で頼む ②一行足す。**どちらに転んでも記事になる設計**（差が出れば見せ場、出なければ「素でも大丈夫だった」と正直に書ける）。今回は差が出た
- **実態ヒアリングが今回も効いた（9本連続）**。「問い合わせ返信をAIに書かせたことがあるか」を先に聞き、**「やっていない」**と判明したので、1本目と同じ「やったことはないが試した」構えで書いた
- **ダミーに引っかけを仕込む手が2本目でも通用した**。業種をバラバラにして、単価・納期／キャンセル規約／返品の可否と送料／担当者名と日付の4種を仕込んだ

- **claude.aiへの長文投入はクリップボード経由**：`osascript -e 'set the clipboard to (read POSIX file "..." as «class utf8»)'` → composerをクリック → `cmd+v` → `Return`。**1回目のcmd+vが空振りすることがあるので、スクリーンショットで確認してから送信する**

### 失敗・引っかかり

1. **⚠️note-posterが1回空振りした**。スキルを読み込んだだけで**ツール実行0回・2秒で完了扱い**になって戻ってきた。→ `SendMessage` で同じエージェントに「実行してください」と投げ直したら正常に完走（101ツール・約16分）。**完了報告が来ても、所要時間とツール実行回数を見て空振りを疑うこと**
2. **⚠️撮影の指示が曖昧で4枚撮り直しになった**。「①素で頼んだ版」と書いたつもりが、ユーザーは②のチャットを4枚撮った。→ **チャットURLと「何という文言が写る範囲か」まで指定して解決**

4. **claude.aiの記憶機能が実演中に発動した**（「Recalled memory ／ Client Operations」）。返信の中身に影響は見えなかったが、**再現性が保証されない**ので記事本文に1行入れた

## 注意点・ブロッカー

### サブエージェント運用（今回更新）

- **⭐note-posterの空振りを疑う基準＝所要時間とツール実行回数**。2秒・0ツールで「完了」が返ることがある。**新しく起こし直さず `SendMessage` で同じエージェントに投げ直す**
- **メイン側でのDOM実測を必ずやる**。今回も実測した（h2/引用/表/画像数に加え、**画像が「どの見出しの直後にあるか」まで1枚ずつ照合**）。Before/Afterの2枚を使う回は順序の取り違えが致命的なので、この照合は毎回やる

### Codex（前回特定した内容が今回も有効だった）

- **長いプロンプトをコマンドラインに直書きするとブロックされる**。**メイン側で先にファイルへ書き、「`"$(cat 絶対パス)"` で渡せ」と指示する**
- **`--model` / `-m` は指定させない**。`--dangerously-bypass-approvals-and-sandbox` は使わない
- プロンプト冒頭に「**`codex exec` を入れ子で呼ばず自分で生成すること**」を必ず書く
- 生成物は**自分で `ls` / `file` / `sips` で実測してから**報告する（今回も実測した：1240×1240・RGBA・アルファあり）

### note運用

- **noteのエディタは表を扱えない**／**インラインの `code` 装飾も取り込まない**
- **composerは座標クリックでは反応しないことがある。refでクリックする**
- **アイキャッチのルートBは寸法で画像を掴む。位置で決めない**
- **公開は朝〜昼に寄せる**（8:59→27／13:08→27／14:58→2／19:22→計測中／20:06→6／22:27→1／22:48→21）
- **記事を書く前にハルト本人の実態をヒアリングする**（9本連続で記事の型が変わっている）
- 編集タブが離脱ダイアログを抱えて閉じられないことがある。**下書きが保存済みなら「破棄」でよい**。今回もタブ1つが「Leave site?」を抱えたまま残った（実害なし）
