## ⭐ 5本目の中身（次回の下敷き）

### 記事の核

**AIに文章を書かせるのをやめて、選ばせるだけにする。** 要約させると「言っていないこと」が混ざるが、原文の抜き書きなら元の文字起こしと突き合わせられる＝**議事録にも検算できる場所ができる**。

### ⭐実演で想定が外れた（ここが今回いちばんの学び）

**素で「議事録にして」と頼んだ版が、予想よりずっと慎重だった。** 仕込んだ引っかけの大半を防いだ：担当未定を⚠️付きで自己申告／値上げを決定事項に入れず「社長預かり」／健診日を確定させない／地味な決定（支払日変更）も落とさず拾う。

**実際に見つかった"言っていないこと"は4か所だけ**：

1. 決定事項に「勤怠システムは**導入を前提に**」（社長は「入れる方向では考えたい**ただ現場が回らないと意味ない**」と留保）
2. 案内送付に「**期限 9月中目安**」（誰も言っていない）
3. 値上げ検討に「**次回月次まで**」（次回までなのは営業のリストだけ）
4. 「**例年**11月第2週」（実際は「**去年は**11月の第2週」）

**抜き書き版で4か所とも消滅し、「発言なし」が18か所。** ゴルフの雑談も「その他（分類外の発言）」に原文で残った＝捨てたことが見える形で捨ててある。

**承認済みの見出し「検討中の話が決定事項になっていました」を、事実に合わせて「思ったより慎重でした。ただ、4か所だけ違いました」に変更した。** 結果的にタイトル（きれいすぎて確かめられない）との相性はむしろ良くなった＝**9割正確、だから残り4か所を探すために全部読む**。

### 成功

- **⭐ダミー素材に「正解表」を付けた**。`ダミー会議_文字起こし.md` の末尾に「実際はどう決まったか」の表を置き、**AIには渡さない**。突き合わせが一瞬で終わり、Before/Afterの差分抽出が速かった。**次回以降もこの形にする**

- **claude.aiへの入力はファイル添付が正解**。`pbcopy` はサンドボックスから触れず0バイト、`type` は改行で送信してしまう。**ファイル添付なら一発**（`find` で file input を掴んで `file_upload`）
- **Codex委譲がうまくいった**。`codex:codex-rescue` サブエージェントに、**プロンプト全文をファイルに書いて `"$(cat 絶対パス)"` で渡す**形。配色hex・フォントパス・参照スクリプトの絶対パス・各画像の文言を全部書いたら、1往復＋修正1回で揃った

### 失敗・引っかかり

1. **⚠️ブラウザ自動操作の `type` が半角数字を落とした**。「3つに分けて」→「つに分けて」で送信されていた。結果は良好だったが、**記事に載せる指示文と実物が食い違う**ので、数字を含まない文言に直して回し直した（チャット1本を捨てた）。**指示文を記事に載せる回は、送信後に画面の文字列を必ず読み返すこと**
2. `pbcopy` / `pbpaste` がサンドボックス有無にかかわらず0バイトで、クリップボード経由の貼り付けが使えなかった
3. `computer` の `wait` は**1回10秒が上限**。長く待つときは複数個を `browser_batch` に並べる
4. claude.ai を開いた直後に「Claudeのメモリ機能のアップデート」ダイアログが出た。**設定は変更せず「後で」で閉じた**（アカウント設定の変更はユーザーの領分）
